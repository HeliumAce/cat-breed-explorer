# UI copy

Use sentence case for all user-facing headings, including section headings, card labels, and dialog titles. Preserve proper nouns such as Cat Breed Explorer, breed names, and organisation or location names. Apply this convention when creating or editing headings; write the intended case in the copy rather than applying automatic case conversion.

Preserve the established footer credits. Ask before replacing footer or attribution wording, or adding explanatory notices beyond the user's requested changes.
